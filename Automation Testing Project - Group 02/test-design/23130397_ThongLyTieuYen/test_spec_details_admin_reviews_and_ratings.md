# Test Specification Details: Admin Reviews & Ratings Management (Maho Commerce)

**Project:** Maho Commerce Automation Testing  
**Environment:** Admin Panel (`https://demo.mahocommerce.com/admin/` hoặc môi trường local `maho/`)  
**Execution Tool:** Playwright Test (TypeScript)  
**Tester:** Thòng Lý Tiểu Yến (MSSV: 23130397)  
**Test Suite:** `Admin Reviews & Ratings - Moderation and Management Flow`  
**Total Test Cases:** 21 (Passed: 16, Failed/Defect: 3, Skipped: 2)

**Shared Test Setup:**
Yêu cầu người dùng đăng nhập tài khoản Quản trị viên (Admin) có đầy đủ quyền hạn truy cập Catalog và quản lý Review (`Catalog > Reviews and Ratings`). Chỉ sử dụng dữ liệu đánh giá mẫu có sẵn trên hệ thống (Seeded Demo Data) hoặc tự khởi tạo ngay trong phiên kiểm thử, đảm bảo tính độc lập hoàn toàn giữa các test case.
